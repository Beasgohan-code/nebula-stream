# NebulaStream

Premium manga, anime, and web series aggregator with multi-source search, in-app streaming/reading, embedded external previews, and AI features.

## Features

- **Manga** — ComicK, MangaDex, MangaPill, and more with chapter reader
- **Anime & Web Series** — HiAnime, AnimePahe, FlixHQ, and fallbacks
- **Hybrid playback** — Native in-app player/reader first; external links open in embedded preview with browser fallback
- **Smart resolve** — Auto-finds readable sources (e.g. MangaDex → ComicK)
- **AI** — Summaries, recommendations, and chat

## Quick Start

```bash
npm run install:all
npm run dev
```

- Frontend: http://localhost:5173
- API: http://localhost:3001

## Production

```bash
npm run build
npm start
```
